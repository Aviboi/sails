# Transatlantic Sail PDR: calculation and decision package

**CUSail · Sails subsystem · Avram Dreyer · baseline v5 (26 Sep 2026) · for PDR on Sun 4 Oct**

This folder is the complete, self-contained record of how the transatlantic rigid sail was sized and placed. Nothing outside it is needed to review or reproduce the work.

## Reading order
1. **`1_Design_Decisions.md`**: the decision log, D0–D9, in the order the decisions were made. Each entry gives the decision, the alternatives, the rationale, the costs and what would make us revisit it, and points to the notebook sections and equations that back it up.
2. **`2_Calculations.ipynb`** (or **`2_Calculations.html`** to read it in a browser without Python): the **current baseline** and what motivates it, front to back.
   - Part 1: inputs, with their sources
   - Part 2: every numbered equation (E1–E68), where it is used and its source
   - Part 3: hull from CAD
   - Part 4: aerodynamic model
   - Part 5: baseline calculations
   - Part 6: why this baseline (section, mast position, trade sweep, size, drive hardware, ballast)
   - Part 7: summary for other subsystems
   - Appendices: references and the assumptions register
3. **`3_Design_History.ipynb`** (or `.html`): the earlier estimates v0 → v4, re-run with the main notebook's method. Only needed to see how the baseline was reached.
4. **`4_Section_Design.ipynb`**: the exact plate cross-section (camber, thickness, edge radius, spine). Standalone; equations are numbered S1–S19 so they do not clash with E1–E68.

## Running the notebook
- Python 3.9+ with `numpy`, `matplotlib` and Jupyter: `pip install numpy matplotlib notebook`
- Open `2_Calculations.ipynb` from this folder and **Run All**. It takes about 3 minutes, or about 4 if the buoyancy cache has to be rebuilt. `3_Design_History.ipynb` takes about the same, because it runs the main notebook first.

## Updating it
- **A new input** (keel CLR, rudder size, displacement, a measured plate moment, …): change the value in notebook **Part 1** and Run All. Every downstream number, table and plot updates.
- **A new hull CAD:** re-measure the ten numbers per station into `data/hull_stations_from_CAD.csv` (Part 3.1 shows what each one is), delete `data/heeled_buoyancy_curves.csv`, and Run All.
- **A new decision:** add it to `1_Design_Decisions.md` with the next D-number and a version tag. Put the supporting calculation in notebook Part 6, and add any new equation to Part 2 with the next E-number. When a baseline is superseded, move its numbers into `3_Design_History.ipynb` as a new H-section.
